兩週 C++ 備考安排：先練 S Tier，A Tier 補常見題型，B Tier 有餘裕再做。

## Tier list

| Tier | 題型 | 優先程度 |
|---|---|---|
| S | Array / String、HashMap / HashSet、Two Pointers、Sliding Window、Stack、Binary Search、Tree DFS / BFS、Graph DFS / BFS、Heap | 優先掌握 |
| A | Linked List、Prefix Sum、Sorting / Intervals、Backtracking、Basic DP、Topological Sort | 第二優先 |
| B | Trie、Union Find、Bit Manipulation、Advanced DP、Advanced Graph、Segment Tree / Fenwick Tree | 有時間再補；Segment Tree / Fenwick Tree 可暫時跳過 |

Tier 決定投入比重；下表是每日練習安排，會穿插 A Tier。

## 練習與複習

- 每天：模板默寫 20～30 分鐘 → 新題 60～90 分鐘 → 錯題重寫 30～60 分鐘。
- 每題：先用 5 分鐘判斷 Pattern；卡住先看 Hint，30 分鐘仍無法完成再看解答。
- 錯題記錄「認不出 Pattern」或「知道但寫不出」，隔 1 天、3～4 天不看答案重寫。
- 考前 3 天以限時練習為主，檢查空輸入、重複值、負數、溢位與複雜度。目標：Easy 5～15 分鐘、常見 Medium 15～30 分鐘。
