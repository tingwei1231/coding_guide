## 先說明你在計算什麼

令 n 為輸入元素數，m 為另一輸入長度。Big O 描述成長上界，不是實際秒數。面試時先定義變數，再說明哪個操作重複多少次，最後分開報告時間、額外空間與输出空間。

## 1. O(1)：讀取固定位置

已知有效索引時讀取陣列 a[3]，輸入變長不會增加讀取次數。只保留一個變數，額外空間 O(1)。如果讀取的是長字串後再完整複製，複製部分不能算常數。

口述：「我只存取固定數量的位置，沒有隨輸入長度增加的走訪，因此是 O(1)。」

## 2. O(log n)：搜尋範圍每次減半

二分搜尋的候選數依序是 n、n/2、n/4，直到約 1；經過 k 次後 n/2^k≈1，所以 k≈log₂n。每次判斷為 O(1) 時，時間 O(log n)，迭代索引的額外空間 O(1)。

二分答案若每次要掃描 n 項判斷可行性，速度範圍上界為 M，總時間是 O(n log M)，不能只報 O(log n)。見[二分答案教學](/guided-learning/binary-search)。

## 3. O(n)：左右指針各只走一次

滑動窗口雖然 while 寫在 for 內，left 與 right 卻都只往前，各最多移動 n 次。合計不超過 2n 次，所以是 O(n)，不是看見巢狀迴圈就判定 O(n²)。只存總和與索引時額外空間 O(1)。

若窗口另外保留字元集合，空間改為 O(min(n,Σ))；Σ 是字元集大小。見[窗口教學](/guided-learning/sliding-window)。

## 4. O(n log n)：排序後掃描

以最差 O(n log n) 的比較排序先處理 n 個值，再線性掃描，時間為 O(n log n+n)=O(n log n)。但排序的額外記憶體依實作不同；若先複製 n 個輸入，至少需要 O(n) 額外空間。

若外層固定一個值，內層雙指針各掃 O(n)，則 3Sum 最後變成 O(n²)，排序不再是主導項。見[多指針模板](/templates/two-pointers#variation-three-sum)。

## 5. O(n²)：列舉所有兩個位置

枚舉 i<j 時，配對數是 (n-1)+(n-2)+…+1=n(n-1)/2。每對做常數運算，時間 O(n²)；若只保存目前最佳答案，額外空間仍是 O(1)。時間二次方不表示空間也二次方。

面試可說：「我先用所有位置配對建立基準，接著利用短邊限制安全淘汰候選，把容器題降為線性。」见[雙指針教學](/guided-learning/two-pointers)。

## 6. 遞迴：狀態數、每個狀態成本與堆疊深度

子集合有 2^n 個結果，輸出每個路徑還需要複製，總時間與輸出大小為 O(n·2^n)，路徑和呼叫堆疊 O(n)。不能只用最大深度 n 推論總時間 O(n)。

House Robber 的樸素遞迴反覆解相同後綴；記憶化後只有 n 個不同狀態，每個做常數轉移，時間 O(n)、記憶表與堆疊 O(n)。bottom-up 可壓縮成 O(1) 額外空間。见[DP 教學](/guided-learning/dp)。

## 如何檢查自己的分析

1. 輸入變數是 n，還是 V、E、R、C、M？先定義。
2. 算總操作次數，不只看程式縮排；雜湊平均成本也要說明假設。
3. 計入切片、排序複本、遞迴堆疊與輸出。
4. 區分單次最差和攤銷：動態陣列擴容一次可 O(n)，很多次 append 平均攤銷仍 O(1)。
