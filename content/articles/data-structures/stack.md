## 定義

後進先出（LIFO）：最後加入的元素先被移除。操作只在頂端進行；函式 call stack 也保存尚未完成的呼叫狀態。

## 圖解

![Stack 的結構示意：bottom A、B、top C、pop C](/diagrams/stack.svg)

依序 push A、B、C，pop 會取出 C，下一次是 B。與需要先處理最早節點的 BFS 相反。

## 複雜度

| 操作 | 成本 | 前提與說明 |
|---|---|---|
| push／pop | O(1)，動態陣列 push 為攤銷 O(1) | 擴容單次可能線性 |
| peek 頂端 | O(1) | 須先確認非空 |
| 搜尋任意值 | O(n) | 不是 stack 擅長的操作 |
| 儲存 n 項 | O(n) | 包含未完成的狀態 |

## 適用情境

括號配對、撤銷操作、顯式 DFS。遇到結束符號時，它應匹配最近還沒完成的開始符號。

## 常見誤區

pop 前確認非空。單調 stack 只保留特定候選，和一般 stack 不同；遞迴改成 stack 不會自動消除 O(n) 的儲存需求。
