## 定義

節點保存資料與下一節點參照；雙向串列另保存前驅。位置不靠連續記憶體計算，必須沿連結移動。

## 圖解

![Linked List 鏈結串列 的結構示意：head: A、B、C、null](/diagrams/linked-list.svg)

A -> B -> C，在 A 後插入 X：先令 X.next=B，再令 A.next=X。順序反過來且未保存 B 可能讓後半串列失去參照。

## 複雜度

| 操作 | 成本 | 前提與說明 |
|---|---|---|
| 存取第 i 個位置 | O(n) | 從頭逐節點走訪 |
| 在已知節點後插入 | O(1) | 不包含搜尋位置 |
| 刪除已知後繼節點 | O(1) | 已知前驅才能重接 |
| 依值查找／刪除 | O(n) | 搜尋成本不能省略 |
| 儲存 n 節點 | O(n) | 每節點另有參照 |

## 適用情境

頻繁在已知位置重接、表達可變鏈結或練習指標操作。找環、中點可使用快慢指標。

## 常見誤區

單向串列只知道待刪節點時，不一定能在 O(1) 安全刪除，尤其尾節點。反轉前先保存 next，否則會丟失未處理部分；值相同不代表同一節點。
