# 教材用語規範

中文敘述使用繁體中文。常見程式術語直接使用英文，避免為了中文化增加理解成本；一般敘述仍使用自然中文，不必將整段改成英文。

| 概念 | 統一用語 |
|---|---|
| 滑動區間 | sliding window；一般區間狀態稱 window |
| 固定大小區間 | fixed-size window |
| 列出所有候選 | 動詞用 enumerate，名詞用 enumeration |
| 後進先出結構 | stack；函式呼叫使用 call stack |
| 先進先出結構 | queue |
| 雙端結構 | deque；維持單調性時用 monotonic deque |
| 優先順序結構 | priority queue |
| 鍵值查找結構 | hash map |
| 保存已計算子問題 | memoization |

英文術語與中文之間留一個空格。陣列、字串、索引、遞迴、排序等清楚易懂的用語可保留中文；英文 API、識別字及題目名稱維持原文。版面中的垂直排列不稱 stack，以免與資料結構混淆。

修改術語時同步檢查教材、模板名稱、搜尋關鍵字、題庫解說、可接受答案、圖解與導覽文字。中文重點標籤使用小標題與共用 CSS 樣式。完成後執行 `npm run verify`，確認文字變更沒有破壞引用、答案比對或互動流程。
